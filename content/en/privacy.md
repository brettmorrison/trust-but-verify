# Privacy policy

The short version: **we don't collect anything that identifies you, we don't
sell or share anything, and we don't use cookies.** The rest of this page is
the honest, complete detail behind that sentence — not a legal document
written to sound reassuring, an actual account of what happens.

---

## What this site does not do

- No cookies, of any kind — not for tracking, not for preferences, not for
  anything.
- No accounts, no logins, no passwords to manage.
- No mailing list. Nothing is collected to contact you again later.
- No advertising, no ad trackers, no third-party pixels.
- No selling or sharing of any data, to anyone, ever. There is no data to
  sell.

## What this site does collect

**Anonymous pageview counts, through Cloudflare Web Analytics.** This runs in
Cloudflare's cookie-free, automatic mode: no JavaScript beacon is added to
the page (this site's Content-Security-Policy blocks scripts entirely, and
Web Analytics doesn't need one), and no cookie is set. It tells us which
pages get read and roughly how much traffic the site gets. It cannot connect
a visit to a person, a device, or a return visit — there is nothing stored
that would let anyone try.

**If you use the feedback or translation-help form**, whatever you type into
it is forwarded by email to the people who maintain this project, so we can
read it and, where useful, reply. It is not stored in a database, added to a
mailing list, or used for anything besides answering you. If you'd rather not
use the form at all, email
**translations@trustbutverifyproject.org** directly — same result, same
handling.

**Standard web server logs.** Like effectively every website on the internet,
Cloudflare's infrastructure briefly logs technical request data (like IP
address) for security purposes — detecting attacks, keeping the site online.
This is infrastructure-level logging we don't access or use for anything
about you individually, and it is not analytics.

## Why it's built this way

This is a site about not letting scammers take your information. A site that
quietly took yours anyway — even for a good reason, even if the data was
"just aggregate," even if nobody meant any harm by it — would be the one
thing this project cannot be. So the rule was simple from the start:
structurally avoid collecting what we don't need, rather than collect it and
promise to be careful.

## Questions
