# Vertrauen, aber prüfen

**Sie können weiterhin vertrauen, fügen Sie nur eine Pause hinzu — bevor Sie Geld überweisen, sich irgendwo anmelden, etwas installieren oder jemanden auf Ihren Computer zugreifen lassen.**

> Sagen Sie auf Englisch, wenn jemand abhebt: "German, please"

## Bevor Geld überwiesen wird

Diese Pause besteht aus drei kurzen Prüfungen.

**1. Suchen Sie die Nummer selbst heraus.**

Nicht die Nummer, die man Ihnen gegeben hat. Die auf Ihrer Karte oder Ihrem
Kontoauszug.

**2. Rufen Sie die Person selbst an.**

Legen Sie zuerst auf. Wenn es echt war, ist die Person immer noch da.

**3. Warten Sie einen Tag.**

Ein echtes Problem übersteht eine Nacht Schlaf. Betrug nicht.

## Drei Warnzeichen zum Innehalten

- Der Anruf kam zu Ihnen — Sie haben ihn nicht begonnen.
- Er hat Ihre Gefühle schnell bewegt — Angst, Sorge oder Eile.
- Es geht um eine Übertragung — Geld, einen Code oder Ihren Computer.

## Niemals, kein einziges Mal

- **Keine seriöse Institution akzeptiert Geschenkkarten als Zahlung.**
- **Ihre Bank wird Sie nie bitten, Geld von Ihrem Konto abzuheben.**
- **Sagen Sie niemandem einen Code, den Sie per SMS erhalten haben.**
- **Niemand kommt zu Ihnen nach Hause, um Bargeld oder Gold abzuholen.**

## Kostenlose Hilfe — niemand verurteilt Sie

**833-372-8311** — National Elder Fraud Hotline · Mo–Fr

**877-908-3360** — AARP Fraud Watch · Mo–Fr

Sagen Sie auf Englisch, wenn jemand abhebt: "German, please"

Melden Sie es: ic3.gov · reportfraud.ftc.gov
