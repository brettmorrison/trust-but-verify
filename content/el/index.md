# Εμπιστεύσου, αλλά επαλήθευσε

**Μπορείτε να συνεχίσετε να εμπιστεύεστε, απλώς προσθέστε μια παύση — πριν στείλετε χρήματα, συνδεθείτε κάπου, εγκαταστήσετε οτιδήποτε, ή αφήσετε κάποιον να μπει στον υπολογιστή σας.**

> Πείτε στα αγγλικά όταν απαντήσει κάποιος: "Greek, please"

## Πριν σταλούν χρήματα

Αυτή η παύση είναι τρεις γρήγοροι έλεγχοι.

**1. Βρείτε τον αριθμό μόνοι σας.**

Όχι αυτόν που σας έδωσαν. Αυτόν που είναι στην κάρτα ή στο λογαριασμό σας.

**2. Καλέστε το άτομο μόνοι σας.**

Κλείστε πρώτα το τηλέφωνο. Μετά καλέστε. Αν ήταν αλήθεια, το άτομο θα είναι
ακόμα εκεί.

**3. Περιμένετε μία ημέρα.**

Ένα πραγματικό πρόβλημα επιβιώνει από μια νύχτα ύπνου. Μια απάτη δεν
επιβιώνει.

## Τρία σημάδια που πρέπει να σας σταματήσουν

- Ήρθε σε εσάς — δεν το ξεκινήσατε εσείς.
- Άγγιξε γρήγορα τα συναισθήματά σας — φόβο, ανησυχία ή βιασύνη.
- Θέλει μεταφορά — χρήματα, έναν κωδικό, ή τον υπολογιστή σας.

## Ποτέ, ούτε μία φορά

- **Κανένας νόμιμος οργανισμός δεν δέχεται δωροκάρτες ως πληρωμή.**
- **Η τράπεζά σας δεν θα σας ζητήσει ποτέ να βγάλετε χρήματα από τον
  λογαριασμό σας.**
- **Ποτέ μην πείτε σε κανέναν έναν κωδικό που λάβατε με μήνυμα.**
- **Κανείς δεν έρχεται στο σπίτι σας για να παραλάβει μετρητά ή χρυσό.**
