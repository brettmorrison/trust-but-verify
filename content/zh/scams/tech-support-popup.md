# 假的安全警报弹窗

## 它长什么样

您正在看新闻，或者查点什么东西。突然屏幕被一条警告占满。也许还有警报声。也许还
有个机器人的声音。

> **⚠ 您的电脑已被锁定**
> Windows Defender ——检测到木马病毒
> 您的银行信息正处于风险之中。
> **请勿关闭电脑。**
> 请致电微软支持：1-888-XXX-XXXX

鼠标好像卡住了。窗口关不掉。它可能会全屏显示，怎么都不肯退出。

## 实际发生的事

**您的电脑没有任何问题。**

您点了一个坏广告——往往就是在一个普普通通、正正经经的网站上，因为广告位是被反复
买卖的，骗子也会去买。这条「警告」不过是一个做成系统警报样子的网页。它是一张灾
难的图片，不是一场真正的灾难。

您的电脑没有病毒。什么东西都没有被偷。屏幕上唯一的威胁，是那个电话号码。

**微软不会在错误提示里放电话号码。苹果也不会。任何一款真正的安全软件都不会。**
从来没有哪个操作系统要您打电话给谁。您一旦知道这一个事实，这种骗局就永远失效
了。

## 同一个骗局，反过来演一遍

有时候根本没有弹窗。电话直接响了，对方自称是「微软」或者「您的杀毒软件公司」，
说他们在您的电脑上发现了问题，需要远程连线来修复。

> **技术支持部门永远不会主动先打给您。**

不是微软，不是苹果，也不是任何一家杀毒软件公司。它们没有一个在监控您的机器，所
以没有一个能知道您的电脑出了问题——也就是说，这样一通电话本身就是那个「问题」，
而不是关于问题的提醒。挂断它。如果您想核实，就自己去查这家公司的号码，再打过
去，跟本网站教您的其他事一样。

## 打过去之后会发生什么

接电话的人客气、专业，通常还会让您排队、听等待音乐。他们请您装一个程序，好让他
们「看看」您的电脑——AnyDesk、TeamViewer、LogMeIn、UltraViewer。这些都是真实存
在的工具，本来用于真正的技术支持，此刻却被用来对付您。

然后他们会给您看一些吓人的东西：事件查看器（Event Viewer）里满屏的红色「错
误」（地球上每一台 Windows 电脑都有几百条，都是家常便饭），或者一个命令行窗口
疯狂滚动的文字。看起来惨不忍睹。其实全是表演。

接着账单来了。「清除病毒」收费 200 到 600 美元，或者是一份要签好几年的「安全服
务套餐」。而现在，他们已经拿到了您电脑的远程控制权、您的文件、您保存的密码，往
往还包括您的银行登录信息。

有时候事情还会更进一步。他们「多退」给您一笔钱——一个假屏幕上显示的是 2 万美元
而不是 200 美元——然后哭着求您把多出来的部分退回去，说自己会因此丢掉工作。这就是
一场 400 美元的骗局，怎么变成一场 19,600 美元的骗局。从来没有人真的给您寄过
钱。您屏幕上看到的那个数字，是他们自己打上去的。

事情往往还没完。这经常只是[幽灵黑客骗局](/zh/scams/phantom-hacker)的开场——
「技术员」把您转交给一个假银行，假银行再把您转交给一个假的政府官员。

## 现在就该做的事

**如果弹窗还在您的屏幕上，而您还没打那个电话：**

1. **不要拨打那个号码。**
2. 关闭浏览器。如果关不掉：在 Windows 上按住 Ctrl + Alt + Delete（Mac 上是
   Command + Option + Esc），强制它退出。
3. 如果这也不行，按住电源键，直到电脑关机。**这样做是安全的。** 那条叫您别关
   机的警告在撒谎——它存在的唯一目的，就是让您一直害怕、一直留在那个屏幕上。
4. 重新开机后，不要再打开之前那些标签页。
5. 就这样。您已经处理完了。什么都没被感染。

**如果您已经打了那个电话，还让对方连上了您的电脑：**
请前往[有人进了我的电脑](/questions/i-let-someone-into-my-computer)（英文），
按顺序完成那几个步骤。

---

## 怎样才能再也不会中招

把这句话大声念一遍，您就再也忘不掉：

> **真正的病毒不会给您一个电话号码。**

真正的安全软件会在背景里安安静静地清理问题。它不会对您大喊大叫，不会拉警报，不
会要求您打电话。凡是这么做的东西，都是广告——在这种情况下，是给一场犯罪打的广
告。

## 您做对了

如果您没打那个电话，直接关掉了那个窗口，那您刚刚就打败了一个每年卷走几亿美元的
骗局。那不是运气——那是因为您知道了一件他们指望您不知道的事。

跟别人说说这件事。下一个看到这个屏幕的人，会庆幸您说过。
