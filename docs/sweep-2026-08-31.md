## The two defects worth the sweep

**hreflang was stale, not wrong.** It was hardcoded to the 45 landing pages,
with a comment explaining that deep content was English-only. That was true when
written. It stopped being true: `/scams/phishing` now exists in all 45 languages
and `/right-now` in 6, and none of them were connected. So 45 translations of the
site's most-reported-scam page were competing with each other in search instead
of being served to the reader who needs that language. Pages carrying hreflang go
from 45 to 150. It is now derived from what is actually built, so it stays right
as translation continues rather than depending on a comment being maintained.

**The interpreter table was partly unreachable.** Measured in a browser at 320px:
the table is 491px wide inside a 273px container, and the container was not
focusable. A region that scrolls but cannot be focused cannot be scrolled without
a mouse, so roughly 45% of the helpline and interpreter data was unavailable to
keyboard users. Separately, none of the site's 66 header cells had a `scope`
attribute, so a screen reader had nothing tying 45 rows of helpline values back
to their columns. Both fixed in markup only. No word of safety content changed.

## Checked and found healthy

Reported because "we looked and it is fine" is worth as much as a fix, and
because each of these was a plausible defect worth ruling out.

- **Performance.** Homepage is 2 subresources, 227 KB, zero scripts,
  DOMContentLoaded 10ms. Audio is `preload="none"`, so the 289 MB of narration
  costs nothing until someone presses play. `aspect-ratio` is set, so no layout
  shift. The only real weight is one 218 KB photo, which the already-open PR #3
  addresses. No new performance work was warranted.
- **Mobile.** No horizontal overflow at 320px. Language-switcher links measure
  41.7 × 89.7px, comfortably past the 24px minimum target size.
- **Contrast.** Every palette pair is AAA; the focus indicator is AA.
- **Structure.** Every page has one `h1`, zero heading-level jumps, zero images
  without alt, a `main` landmark and a skip link. Sitemap is 196 of 196 with
  `lastmod`, no orphans, no phantom entries. Zero broken internal links.
- **External links.** All 28 resolve.
- **Reduced motion.** The site has no animations, so nothing to gate.

## Two false positives caught before they became findings

**"36 of 44 language links fail target size."** Measured against a `file://`
snapshot where the stylesheet never loaded, so it was measuring unstyled HTML at
Times 16px. Served properly over HTTP, every link is 41.7px tall and zero fail.

**"A YouTube link is dead."** Its page contains "Video unavailable" — but so
does the page of a known-working video, as boilerplate. `playabilityStatus` is
`OK` for both.

There was also a real self-inflicted one: the first version of the table guard
passed its own injection test because it had been branched off `main` and was
patching a string that only existed on another branch, so it was never wired into
the runner. The wiring is now covered by the same injection test.

## Flagged for Brett, deliberately not changed

> **Non-canonical reporting URL.** Six pages link `https://ic3.gov`, which
> redirects to `https://www.ic3.gov/`; the rest of the site uses the canonical
> form. This is reporting-step content. The six are `lottery-sweepstakes` in
> en/es/vi/zh/ru/ko — the English source is the origin and the five translations
> inherited it, so correcting English and re-translating that one line resolves
> all six. It works today; this is an extra hop, not an outage.

> **The scroll container has no accessible name.** `tabindex` removes the
> keyboard trap, but a screen reader announces the region unnamed. Naming it
> properly needs a `role="region"` plus a label, and a label means new copy in 45
> languages. Not this sweep's call to make.

> **Two over-long meta descriptions**, French (221 chars) and Hmong (206). Both
> are translated copy, so trimming them is a translation change awaiting the
> English-first rule.

## Standing limits

The external link checker cannot see a soft 404: `reportfraud.ftc.gov` answers
200 for a path that does not exist, verified directly. It catches a dead domain,
a DNS failure, a hard 4xx/5xx and a moved address, which is the realistic failure
for the URLs that matter. Written down so nobody trusts it further than it goes.
